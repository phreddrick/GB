## Work unit 7 (PR-G): module path

Files: `go/go.mod` and the 26 Go files that import the module.

- Verified: remote is `git@github.com:phreddrick/GB.git` (capital `GB`) and the module lives in the `go/` subdirectory. The literal path proposed in the plan, `github.com/phreddrick/gb`, is therefore not the canonical import path: Go module paths are case-sensitive, and a module in a subdirectory of a repository is addressed as `<repo>/<dir>`. The module was renamed to **`github.com/phreddrick/GB/go`**, which `go get` and `pkg.go.dev` would resolve. No external module imports this one, so the change has no consumers. If the owner prefers another path, it is one command: `cd go && sed -i 's#github.com/phreddrick/GB/go#<path>#g' go.mod $(grep -rl 'github.com/phreddrick/GB/go' --include='*.go' .)`.
- Build, vet, tests and formatting are unchanged after the rename. The `Dockerfile` does not reference the module path.
